Sobre a Pokédex

Um projeto criado para explorar o universo Pokémon com dados reais, direto da PokeAPI.

Dados em tempo real

Todas as informações vêm diretamente da PokeAPI, sempre atualizadas.

100% responsivo

Funciona bem em celular, tablet e desktop, sem perder qualidade.

Django + Python

Backend robusto, buscando e organizando os dados antes de exibir.

O projeto

A Pokédex nasceu como um projeto de portfólio, unindo front-end estilizado em Bootstrap com um back-end em Django responsável por consumir a PokeAPI e organizar os dados de cada Pokémon.

A ideia é oferecer uma experiência simples, rápida e visualmente marcante pra qualquer fã explorar o universo Pokémon.

Tecnologias utilizadas

Python Django Bootstrap JavaScript PokeAPI
